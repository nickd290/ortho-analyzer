# Orthodontic Case Analyzer Pro

AI-powered orthodontic case analysis with machine learning capabilities.

## 🚀 Live Demo

Once deployed to GitHub Pages, access at:
```
https://YOUR-USERNAME.github.io/ortho-analyzer/
```

## Features

- **AI-Powered Analysis**: Claude Sonnet 4.5 provides expert orthodontic case analysis
- **Machine Learning**: System learns from your corrections and improves over time
- **Comprehensive Reports**: Detailed analysis and treatment planning
- **Review Workflow**: Approve and edit all findings before finalizing
- **Private & Secure**: All data stored locally in your browser

## Quick Start

1. Open the app
2. Enter your Anthropic API key
3. Upload patient images
4. Review AI-generated analysis
5. Generate treatment plan
6. Download reports

## Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Anthropic API key (get from https://console.anthropic.com/)
- Internet connection for API calls

## Cost

Approximately $0.10-0.30 per case analysis.

## Privacy

- API key stored locally in browser
- No backend server
- Images never saved
- All data remains private

## Technology

- React 18
- Tailwind CSS
- Claude Sonnet 4.5 API
- Browser localStorage for learning system
